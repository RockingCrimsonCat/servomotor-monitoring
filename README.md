# Система моніторингу та прогнозування технічного стану сервомоторів

Автономна програмна система для моніторингу сервомоторів у реальному часі та
прогнозування їх технічного стану методами машинного навчання. Система генерує
телеметрію на основі фізичної моделі двигуна постійного струму, класифікує стан
кожного двигуна, виявляє аномалії та формує діагностичні рекомендації у
вебінтерфейсі з автооновленням.

## Можливості

- **Телеметрія в реальному часі** — температура, струм, швидкість, вібрація для
  кожного сервомотора з індивідуальним фізичним профілем.
- **Класифікація стану** — три класи: `NORMAL`, `WEAR`, `FAILURE`.
- **Виявлення аномалій** — Isolation Forest позначає нетипові режими роботи.
- **Діагностика** — кольорові індикатори (зелений / жовтий / червоний),
  ймовірність відмови у відсотках та інженерні рекомендації.
- **Ролі користувачів** — адміністратор (керує операторами, бачить навантаження
  на систему й журнал аудиту) та оператори (моніторять власні двигуни).
- **Вебінтерфейс** на Streamlit з автоматичним оновленням.

## Архітектура

| Модуль | Файл | Призначення |
|--------|------|-------------|
| 1 | `module1_data_generator.py` | Генератор телеметрії за фізичною моделлю двигуна |
| 2 | `module2_ml_models.py` | Random Forest (класифікація) + Isolation Forest (аномалії) |
| 3 | `module3_diagnostics.py` | Діагностичний контур, рекомендації, ймовірність відмови |
| 4 | `module4_gui.py` | Вебінтерфейс (Streamlit) |
| 5 | `module5_user_registry.py` | Реєстр користувачів, сервомоторів і журнал аудиту |

## Запуск

Потрібен Python 3.11+.

```bash
# 1. Створити та активувати віртуальне середовище
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

# 2. Встановити залежності
pip install -r requirements.txt

# 3. Запустити застосунок
streamlit run module4_gui.py
```

> При першому запуску система автоматично згенерує навчальний датасет і навчить
> обидві моделі (каталоги `data/` та `models/` створюються самі). Окремих
> підготовчих кроків не потрібно.

Вхід виконується за іменем користувача. Адміністратор має ім'я `admin`; він
створює облікові записи операторів, після чого оператори входять за своїми
іменами.

## Структура даних (генерується автоматично)

```
data/
  training_dataset.csv     # навчальний набір
  streams/                 # журнали телеметрії по кожному двигуну
models/
  rf_classifier.joblib     # навчений Random Forest
  iforest.joblib           # навчений Isolation Forest
```
